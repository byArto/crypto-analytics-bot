## 🚀 Как это работает

### Источники событий

**Приоритет 1: Статический список** (файл: modules/events.py, строка 62-98)
```python
static_events = [
    "US CPI Data Release" (высокая важность),
    "US Federal Reserve FOMC Meeting" (высокая важность),
    "Token Unlock: APT" (средняя важность),
    "Bitcoin Halving" (высокая важность),
    "Ethereum Pectra Upgrade" (средняя важность),
]
```

**Приоритет 2: Внешние API** (резерв на будущее)
- CoinGecko Events API (пока недоступен в бесплатной версии)
- Можно добавить CoinMarketCal Pro, LunarCrush и др.

### Кэширование

События кэшируются на **6 часов**. Это означает:
- Первый запрос `/events` загружает события
- Следующие запросы в течение 6 часов берутся из кэша (мгновенно)
- Через 6 часов кэш автоматически обновляется

### 30-минутные оповещения

Планировщик проверяет события каждые **5 минут**:
1. Получает список всех high-importance событий
2. Проверяет, осталось ли до события 25-35 минут
3. Если да - отправляет оповещение в `ALERT_CHAT_ID`
4. Сохраняет ID события чтобы не дублировать

### Персистентность оповещений

Все отправленные оповещения сохраняются в файлы:
- `data/alerted_events.json` - общие оповещения
- `data/alerted_30min_events.json` - 30-минутные оповещения

Это предотвращает дубликаты после перезапуска бота.

## 📝 Обновление списка событий

### Как добавить новое событие

Откройте файл `modules/events.py` и найдите функцию `fetch_static_crypto_events()` (строка 49).

Добавьте новое событие в список `static_events`:

```python
{
    "title": "Название события",
    "description": "Описание события и его влияния на рынок",
    "start_date": "2026-02-15T14:00:00.000Z",  # Формат: ISO 8601
    "type": "Event",
    "importance_keywords": ["ключевые", "слова"],  # Для определения важности
},
```

### Определение важности

События автоматически классифицируются по ключевым словам:

**Высокая важность (🔴):**
- mainnet launch, hard fork, halving
- binance listing, coinbase listing
- major upgrade, token burn, airdrop
- **fomc, fed, cpi, inflation, federal reserve, interest rate**

**Средняя важность (🟠):**
- unlock, vesting, token release
- update, upgrade, ama
- partnership, integration

**Низкая важность (🟢):**
- Все остальные

### Периодичность обновления

Рекомендуется обновлять список событий:
- **Раз в месяц** - добавлять предстоящие макро-события (CPI, FOMC)
- **По мере необходимости** - важные анлоки токенов, хардфорки, листинги
- **Автоматически (будущее)** - подключить платный API для автообновления
